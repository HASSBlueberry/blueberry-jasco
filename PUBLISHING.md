# Publishing Blueberry Jasco myTS

This directory is a standalone Home Assistant integration repository for `blueberry_jasco`. Publish this directory as its own GitHub repository to submit it to Home Assistant Marketplace. The integrations are intentionally split because Marketplace repositories publish one integration each.

Experimental myTouchSmart Wi-Fi paths. Use the built-in Jasco integration for Z-Wave products and the vendor app for remote control.
